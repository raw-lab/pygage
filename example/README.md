# Examples

Runnable examples for PyGAGE.

## Quickstart

```bash
pip install -e ".[anndata]"     # from the repo root
python examples/quickstart.py
```

`quickstart.py` runs a full GAGE analysis on the shipped `gse16873` demo data
(no downloads), demonstrating the one-call `gage()` API, the explicit
two-step API with effect size + leading-edge genes, and a bubble plot.

See the full documentation at https://pygage.readthedocs.io.
